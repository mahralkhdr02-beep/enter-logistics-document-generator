# Enter - Smart Logistics Document Generator

A professional, client-side B2B SaaS utility designed to streamline and automate international shipping and trade document generation.

## 🚀 Features
- **Smart Paste Parser:** Instantly extracts and populates shipping details from unstructured text.
- **Dynamic Company Branding:** Allows custom company headers for Commercial Invoices, Packing Lists, and Draft B/L.
- **100% Privacy (Zero-Server):** All data is processed locally within the user's browser memory. No trade data is stored or transmitted externally.
- **Cross-Platform & Clean Print:** Fully responsive and optimized for seamless exporting to PDF and Excel.
